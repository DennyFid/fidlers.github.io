Blog feature removed
=====================

- The api/ serverless handlers and SQL schema file for comments were removed.

Security reminder
-----------------
If you exposed any Supabase service keys or admin keys during testing, rotate them now in your Supabase project settings and remove them from any environment where they were stored.
